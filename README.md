# rag-conformidade-laticinios

> **Status: em construção** (Fase 0 — engenharia de requisitos). README completo na Fase 3.

RAG agêntico que responde perguntas sobre **conformidade e qualidade na indústria de
laticínios** com base exclusivamente em **documentos públicos oficiais** (legislação do
MAPA, RIISPOA, manuais públicos da Embrapa) — **toda afirmação cita a fonte** (documento +
artigo/seção); sem base recuperada, o sistema responde honestamente que não encontrou.

Projeto 2 do portfólio de AI engineering — mesmo padrão de disciplina do
[agente-credito-langgraph](https://github.com/EnzoKoeche/agente-credito-langgraph).

Documentação de requisitos em [`docs/`](docs/). Progresso em [`PROGRESSO.md`](PROGRESSO.md).
